PORTFOLIO EXTERNAL REFERENCE - COME AGGIORNARE LE FOTO

Le foto del sito sono nella cartella "foto", una cartella per progetto:

  foto/00_home        le 4 immagini dei riquadri della home (01 Studio, 02 Urban, 03 Interior, 04 Art)
  foto/01_studio/...  le immagini delle pagine Studio
  foto/02_urban/...   Urban & Architecture
  foto/03_interior/.. Interior
  foto/04_art/...     Art & Collectible Design

AGGIUNGERE O SOSTITUIRE UNA FOTO
1. Su GitHub apri la cartella del progetto (es. foto/03_interior/02_alkimia).
2. Add file > Upload files, trascina la foto (JPG, PNG o TIFF, anche ad alta risoluzione, max 25 MB).
3. Chiamala con il numero della posizione: 05.jpg diventa la quinta foto.
   Se esiste già 05.webp, la nuova foto la sostituisce.
4. Commit changes.
In 2-3 minuti GitHub converte la foto (WebP, lato lungo 2400 px, mai ritagliata),
aggiorna la miniatura e ripubblica il sito. Poi ricarica la pagina con Ctrl+F5 (Mac: Cmd+Shift+R).

TOGLIERE UNA FOTO
Apri il file .webp nella cartella del progetto, menu ... > Delete file > Commit changes.

ORDINE
Le foto si vedono in ordine di nome: 01, 02, 03... La 01 è la copertina del progetto.

NOTE
- Non rinominare le cartelle: il nome dice al sito a quale progetto appartengono le foto.
- La cartella "miniature" e il file "foto.js" si aggiornano da soli: non toccarli.
- Un progetto nuovo (cartella nuova) ha bisogno anche di titolo e testi: va aggiunto a index.html.
- Per seguire l'aggiornamento: scheda "Actions" del repository (pallino verde = fatto).
